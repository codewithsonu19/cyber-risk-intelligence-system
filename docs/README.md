# CyRIQ

## AI-Powered Continuous Cyber Risk Quantification and Investment Optimization Platform

CyRIQ is a cybersecurity platform that helps organizations identify, quantify and prioritize cyber risks.

## Main Features

- Asset Inventory
- Vulnerability Analysis
- Cyber Risk Quantification
- Financial Risk Exposure
- Investment Optimization
- Risk-based Security Prioritization

## Technology Stack

- Python
- FastAPI
- Streamlit
- Pandas
- Scikit-learn
- SQLite

## System Workflow

Asset Data
↓
Vulnerability Analysis
↓
Risk Quantification
↓
Financial Exposure
↓
Investment Optimization
↓
Security Recommendation

## Example

Customer Database:

- Criticality: 9/10
- CVSS: 9.8
- Likelihood: 0.6
- Estimated Loss: ₹20 Lakh
- Current Risk Exposure: ₹12 Lakh
- Expected Risk: ₹3 Lakh
- Risk Reduction: ₹9 Lakh
